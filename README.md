# KYS — Keep Yourself Safe

A compact, pharmaceutical-inspired landing page for the KYS internet project. KYS is presented as paired against JNJ stock exposure, with 1/1 (100%) of protocol fees routed toward JNJ distributions for eligible holders. The build is intentionally dependency-free and uses plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` directly, or run the included zero-dependency local server:

```powershell
npm.cmd run dev
```

## Safety note

The “Keep yourself safe” actions open an accessible resources dialog with emergency and crisis-support routes. The site does not provide medical or investment advice and states its independence from Johnson & Johnson and SPRAVATO®.
